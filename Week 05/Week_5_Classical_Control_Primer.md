# Week 5 Primer — Classical Control

## Purpose
Build intuition for feedback control and the tools used to analyze linear systems.

## Topics
- Open-loop vs closed-loop systems
- Laplace transforms
- Transfer functions
- Poles and zeros
- Stability
- Step response metrics
- Root locus
- Bode plots
- Gain and phase margin
- PID control
- Lead/Lag compensation

## Aerospace Applications
- Aircraft pitch and roll control
- Cruise control
- Servo actuators
- Engine speed regulation

## Key Takeaways
- Feedback reduces sensitivity to disturbances.
- Pole locations determine dynamic behavior.
- Frequency response predicts robustness.
- PID is simple but has limitations for multivariable systems.

## Common Pitfalls
- Tuning derivative gain on noisy measurements.
- Ignoring actuator saturation.
- Using only time-domain metrics.

## Suggested Reading
- Feedback Systems (Åström & Murray)
- Aircraft Control and Simulation (Stevens & Lewis)
