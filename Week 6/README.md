# Week 6 Guidance & Trajectory Generation Python Projects

Run any file with:

```bash
python filename.py
```

Recommended install:

```bash
pip install numpy matplotlib
```

Projects:
1. waypoint_navigator — basic waypoint navigation, desired heading, distance-to-go.
2. line_of_sight_guidance — line-of-sight guidance and heading commands.
3. pure_pursuit_path_follower — lookahead distance, curvature, smooth path tracking.
4. cross_track_error_analyzer — path deviation metrics.
5. proportional_navigation_intercept — LOS rate, closing velocity, intercept guidance.
6. dubins_path_generator — minimum turning radius path concepts.
7. smooth_trajectory_generator — velocity/acceleration limited trajectory generation.
8. obstacle_avoidance_toy_planner — simple path planning with obstacle penalties.
9. randomized_mission_campaign — Monte Carlo guidance robustness testing.
10. guidance_architecture_package_demo — reusable mission/planner/guidance/controller/vehicle structure.
