# Week 5 Classical Controls Python Projects

Run any file with:

```bash
python filename.py
```

Recommended install:

```bash
pip install numpy matplotlib
```

Projects:
1. first_order_step_response — time constant, rise time, settling.
2. second_order_playground — damping ratio, natural frequency, overshoot.
3. mass_spring_damper — physical second-order dynamics.
4. pid_temperature_controller — P/I/D intuition.
5. cruise_control_simulator — PID tuning and disturbances.
6. servo_position_controller — overshoot and settling time.
7. drone_altitude_hold — disturbance rejection and actuator limits.
8. boat_heading_controller — heading control and integral action.
9. waypoint_following_vehicle — multiple PID loops.
10. inverted_pendulum — unstable system stabilization.
11. ball_on_beam_controller — stability and sensitivity.
12. bode_plot_explorer — frequency response, magnitude, phase.
13. gain_margin_experiment — instability from excessive gain.
14. phase_margin_experiment — feedback delay and phase lag.
15. sensor_noise_investigation — derivative noise sensitivity.
16. actuator_saturation_demo — integral windup and anti-windup.
17. monte_carlo_pid_campaign — statistical robustness.
18. disturbance_rejection_challenge — compare disturbance types.
19. pid_auto_tuner — gain search and objective functions.
20. controller_comparison_suite — P vs PI vs PD vs PID.
