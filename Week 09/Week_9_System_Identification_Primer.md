# Week 9 Primer — System Identification

## Purpose
Learn how to build mathematical models directly from telemetry.

## Topics
- Least squares
- Recursive least squares
- ARX models
- State-space identification
- Residual analysis
- Cross validation
- Bootstrap uncertainty
- Neural network identification

## Aerospace Applications
- Aircraft aerodynamic modeling
- Engine parameter estimation
- Fault detection
- Digital twins

## Key Takeaways
- Models are only as good as the excitation data.
- Validation is as important as fitting.
- Residuals reveal missing dynamics.

## Exercises
- Compare linear and nonlinear models.
- Study parameter correlation effects.
