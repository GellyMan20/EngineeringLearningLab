# Week 9 — System Identification (Commented Educational Edition)

This package preserves the original runnable Week 9 projects and adds an instructional structure modeled after an engineering course.

Every script includes:

- Project title and purpose
- Key concepts
- Learning outcomes
- Explanatory import comments
- Comments around important estimation and validation steps
- The original working implementation

## Install

```bash
pip install numpy matplotlib scipy scikit-learn
```

## Recommended progression

### Foundations
Projects 01–06 cover physical parameter estimation, transfer functions, state-space identification, and ARX models.

### Validation and identifiability
Projects 07–16 cover residual analysis, excitation, sensitivity, train/validation splits, uncertainty, model order, and cross-validation.

### Advanced and capstone work
Projects 17–24 cover neural-network identification, anomaly detection, the Dynamics Identification Tool, validation reporting, parameter correlation, residual whiteness, and operating-region validation.

## Recommended study method

1. Read the purpose and key concepts.
2. Predict what the output should look like.
3. Run the script unchanged.
4. Modify one model parameter, noise level, or input profile.
5. Explain why the results changed.
6. Record conclusions in a model-validation report.
