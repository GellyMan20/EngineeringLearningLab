
# Building Simulations

## Engineering Workflow
1. Define the question.
2. Build a deterministic model.
3. Identify uncertain inputs.
4. Select probability distributions.
5. Generate samples.
6. Run simulations.
7. Analyze outputs.
8. Verify and validate.

## Choosing Sample Size
Increase samples until statistics converge.

## Validation Questions
- Does the model represent reality?
- Are assumptions documented?
- Are inputs justified?
