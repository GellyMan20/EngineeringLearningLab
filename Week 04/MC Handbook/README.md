# Monte Carlo Handbook

Welcome to the Monte Carlo Handbook for the Engineering Learning Lab.

## Purpose
This handbook is a structured reference on Monte Carlo simulation for engineering,
verification & validation, guidance, navigation & control (GNC), reliability, and
decision making under uncertainty.

## Reading Order
1. Foundations
2. Building Simulations
3. Engineering Applications
4. Advanced Monte Carlo
5. Sensitivity and Robustness
6. Visualization
7. Engineering Workflow
8. Related Methods
9. Python Cookbook
10. Aerospace Case Studies
11. Common Mistakes
12. Further Reading

## Core Workflow
Question → Model → Uncertain Inputs → Sampling → Simulation → Analysis →
Sensitivity → Recommendation → Verification

This handbook is designed as a living reference. Expand each chapter with your own
notes, projects, and lessons learned.
