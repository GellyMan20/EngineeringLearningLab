# Week 10 — Advanced Control (Commented Educational Edition)

This package contains the original 24 runnable Week 10 activities, expanded with project-specific purposes, engineering context, mathematical foundations, learning objectives, suggested experiments, docstrings, and inline implementation comments.

Start with `WEEK_10_ADVANCED_CONTROL_PRIMER.md`, then complete the numbered scripts in order.

## Install

```bash
pip install numpy matplotlib scipy control
```

## Learning sequence

- Projects 01–05: state-space foundations, controllability, pole placement, and LQR.
- Projects 06–10: PID/LQR comparison, integral action, digital control, and tracking.
- Projects 11–16: uncertainty, Monte Carlo, gain scheduling, saturation, noise, and LQG.
- Projects 17–24: trade studies, metrics, recommendations, Pareto analysis, and reporting.

## Study method

1. Read the primer section associated with the activity.
2. Read the project header before running the code.
3. Predict the result.
4. Run the original configuration.
5. Complete at least one suggested experiment.
6. Record the engineering conclusion, not only the plot.
